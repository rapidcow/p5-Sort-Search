=head1 NAME

Sort::Search::Cookbook - practical examples for Sort::Search

=head1 DEFINITION

The functions "predicate", "ordering", "search range" are
the same as they are defined in L<Sort::Search/DESCRIPTION>.
In addition, assume these variables mean the following:

=over

=item C<$_>

The current element during a search.

=item C<$idx>

The array index result found by a search.
The index may not correspond to a real
element in the array, in which case the
following two variables would be C<undef>.

=item C<$cmp>

The comparison result returned by the
predicate/ordering on the found element.
If there is no such element, this is C<undef>.

=item C<$elt>

The found element, or C<undef> if none was found.

=back

You import the appropriate functions into your
current namespace like this:

    use Sort::Search qw( blsrch0 blsrch1 );
           # imports `blsrch0', `blsrch1'

... you get the point.  If you need more just add
more to the list. :)

=head1 EXAMPLES

=head2 Exact match

Given the numerically sorted array:

    my @array = qw( 12 17a 17b 17c 21 );

and the numeric ordering:

                          (-) $_  precedes $want
    sub { $_ <=> $want }  (0) $_  equals   $want
                          (+) $_  follows  $want

you can find the first match like this:

    sub lsearch {
        my ($array, $want) = @_;
        my ($idx, $cmp, $elt) = blsrch0 { $_ <=> $want } $array;
        if (!defined $cmp) { print "$want not found anywhere\n"; }
        elsif ($cmp != 0)  { print "$want not found; best "
                                 . "I got was $elt [$idx]\n"; }
        else               { print "$want found at $elt [$idx] :)\n"; }
    }

    lsearch \@array => 11;  # 11 not found; best I got was 12 [0]
    lsearch \@array => 12;  # 12 found at 12 [0] :)
    lsearch \@array => 17;  # 17 found at 17a [1] :)
    lsearch \@array => 21;  # 21 found at 21 [4] :)
    lsearch \@array => 99;  # 99 not found anywhere

or the last match (17c) by index like this:

    sub rsearch {
        my ($array, $want) = @_;
        my ($idx, $cmp, $elt) = brsrch0 { $want <=> $_ } $array;
        if (!defined $cmp) { print "$want not found anywhere\n"; }
        elsif ($cmp != 0)  { print "$want not found; best "
                                 . "I got was $elt [$idx]\n"; }
        else               { print "$want found at $elt [$idx] :)\n"; }
    }

    rsearch \@array => 11;  # 11 not found anywhere
    rsearch \@array => 12;  # 12 found at 12 [0] :)
    rsearch \@array => 17;  # 17 found at 17c [3] :)
    rsearch \@array => 21;  # 21 found at 21 [4] :)
    rsearch \@array => 99;  # 99 not found; best I got was 21 [4]

Notice that the ordering is reversed: C<< $want <=> $_ >>
instead of C<< $_ <=> $want >>, due to using a right search
instead of a left search.  The conventional left search may be
used, though you must check and retrieve the element yourself:

    sub rsearch {
        my ($array, $want) = @_;
        my $idx = blsrch1 { $_ <=> $want } $array;
        --$idx;
        if ($idx < 0) {
            print "$want not found anywhere\n";
        } else {
            my $elt = $array->[$idx];
            my $cmp = $elt <=> $want;
            print $cmp == 0
            ? "$want found at $elt [$idx] :)\n"
            : "$want not found; best I got was $elt [$idx]\n"
        }
    }

    # The output is identical to above.

To get all matches at once, use C<blsrch2> or C<brsrch2>:

    sub srchall {
        my ($lo, $hi);
        my ($array, $want) = @_;

        # EITHER:
        ($lo, $hi) = blsrch2 { $_ <=> $want } $array;
        print "[$_]=$array->[$_] " for ($lo .. $hi-1);

        # OR:
        ($hi, $lo) = brsrch2 { $want <=> $_ } $array;
        print "[$_]=$array->[$_] " for ($lo+1 .. $hi);
    }

    srchall \@array => 11;  # <empty>
    srchall \@array => 12;  # [0]=12
    srchall \@array => 17;  # [1]=17a [2]=17b [3]=17c
    srchall \@array => 21;  # [4]=21
    srchall \@array => 99;  # <empty>

Note that the left search range is right-exclusive and
the right search is left-exclusive.
